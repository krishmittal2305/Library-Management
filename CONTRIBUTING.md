# Contributing to Library Management System (LMS)

First off, thank you for considering contributing to LMS! It's people like you that make open-source software such a great community to learn, inspire, and create.

## Getting Started

1. Fork the repository and create your branch from `main`.
2. Ensure you have the .NET 8 SDK installed.
3. If you've added code that should be tested, add tests.
4. If you've changed APIs, update the documentation.
5. Ensure the test suite passes (if applicable).
6. Make sure your code lints and follows the Microsoft C# Coding Standards.

## Issues

When opening an issue, please ensure you use the provided templates for Bug Reports or Feature Requests. 
- Provide as much context as possible.
- Include screenshots if it's a UI issue.
- Mention your environment (.NET version, OS, browser).

## Pull Requests

1. Use the PR template provided when opening a pull request.
2. Ensure your branch is up to date with the `main` branch before submitting.
3. Link the PR to any related issues.
4. Provide a clear and descriptive title for your PR.

## Code Style

- We follow standard [Microsoft C# Coding Conventions](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/coding-style/coding-conventions).
- Use `PascalCase` for classes and methods.
- Use `camelCase` for local variables and method arguments.
- Prefix private fields with `_`.
